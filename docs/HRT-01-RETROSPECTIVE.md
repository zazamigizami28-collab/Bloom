# HRT-01 開発総括 — v0.6.11

## 完了の位置付け
2026-09-16、ユーザーの判断によりHRT-01の開発を終了。Phase 6の基準ボスとして保存する。Phase 7（演出・SE・カメラ）は未着手。完成判断と自動検証、実機検証は別記する。v0.6.11の発光は480ms（白化240ms）へ修正し、自動検証対象とした。実プレイ評価は未取得。今後の修正は不具合か新しい依頼として別版にする。

## 成立した体験
植木鉢頭の主人公が園芸機械と戦い、水を受けて育つ。通常パリィで崩す、特殊パリィで成長する、開花中の攻撃に花風が乗る、BREAKで専用一撃という循環。画面はボス戦と練習場を独立させ、練習で得たタイミングを本戦に持ち込む。

## 現行仕様（旧監査の数値より優先）
- TypeScript / Phaser / Vite / Web Audio。PCキーボード・パッド。A/D移動、Wジャンプ、Space回避、J攻撃、Kパリィ、E回復。
- HP5。通常パリィ受付180ms、ジャスト60ms。押下開始。白化は攻撃240ms前、音は160ms前。
- 共通光は480ms前から点灯・収縮、240ms前に白化、攻撃時に消灯。赤攻撃は外輪が赤。光開始時点の即入力は早すぎる。発射合図と弾の着弾は別。
- 通常/ジャストBREAK19/25、最大100、停止3秒、近接Jで専用一撃。敵弾パリィは蓄積0。通常攻撃4、花風命中8は別報酬。
- 水1回で1段階、3回で開花20秒。被弾で成長は失わない。通常攻撃に花風、終了時種へ。肥料モデルは練習場/デバッグに残るがHRT-01は肥料弾を出さない。
- 回復HP2・3回・1.2秒。完了時だけ消費、被弾中断で消費なし。行動中は移動/回避不可。再戦で補充。
- ボス高さ295、主人公59。初期中心距離455。HP650、半分で第二形態。近210/遠360を目安に行動選択。
- 通常形態3段、第二形態4段。赤は高枝剪定最終段だけ。地面攻撃は現在の選択肢から除外。
- 通常弾→通常弾→水。敵弾半径18。射出後の弾は直進。ボス各段の方向は160ms前に固定。
- 通常接触で通過不可。ローリング420ms、距離182、開始から750msで再使用。

## 継続する課題
自動テストは触感・見やすさ・実パッドを保証しない。Phaserの大きな配布チャンク警告、実装基準v0.5原文の逐条照合未完了は残る。複数ボス用の登録機構は未実装。回復音は成長音を再利用しており、Phase 7で独立した音の必要性を判断する。

## Phase 7への引継ぎ
今回の戦闘数値を基準として保存し、演出・音・カメラの変更で入力判断を壊さない。光の視認性、攻撃方向、赤の識別、次段を隠さない粒子、ヒットストップ時の同期を優先確認。Phase 7開始は次回指示で行う。
